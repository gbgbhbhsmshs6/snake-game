# 贪吃蛇（C 语言控制台版）

一个给 C 语言初学者练手用的贪吃蛇项目。**纯 C 标准库 + 少量系统调用，不依赖任何第三方库**，两百多行代码，跑在终端里。

```
######################
#                    #
#      OOO@          #
#                    #
#            *       #
#                    #
#                    #
######################
得分: 30   长度: 6    速度: 140
W/A/S/D 移动   P 暂停   Q 退出
```

## 项目结构

| 文件 | 说明 | 建议学习顺序 |
| --- | --- | --- |
| `step1_board.c` | 只画一个空棋盘 + 随机放一颗食物 | ① 先跑这个 |
| `step2_snake.c` | 蛇自动向右跑，会吃食物、会变长、会撞墙 | ② 再读这个 |
| `snake.c` | 完整版：键盘控制、计分、加速、暂停、重开 | ③ 最后看这个 |

三个文件是递进的，**不要一上来就读 `snake.c`**。先把前两个彻底搞懂，"蛇为什么会动"这个问题想清楚了，最后一个文件就只是给它加外壳。

## 编译运行

### Windows（MinGW / gcc）

```bash
# 如果你装了 VS Code + MinGW，直接在终端里：
gcc snake.c -o snake.exe
snake.exe
```

如果没有编译器，去装 [MSYS2](https://www.msys2.org/) 或 [MinGW-w64](https://www.mingw-w64.org/)，装完确认 `gcc --version` 能输出版本号。

### Linux / macOS

```bash
gcc snake.c -o snake
./snake
```

代码里用 `#ifdef _WIN32` 做了平台适配，两个平台都能直接编译，不需要改任何东西。

### 建议加上警告选项

```bash
gcc -Wall -Wextra -std=c11 snake.c -o snake.exe
```

`-Wall -Wextra` 会把你写的大部分低级错误（未初始化变量、类型不匹配、漏写 return）在编译阶段就报出来。**初学阶段强烈建议每次都加**，它能帮你省掉大量调试时间。

## 操作说明

| 按键 | 功能 |
| --- | --- |
| `W` `A` `S` `D` | 上 / 左 / 下 / 右 |
| `P` | 暂停 / 继续 |
| `R` | 游戏结束后重开一局 |
| `Q` | 退出 |

> 为什么不用方向键？因为方向键在终端里不是一个字节（Windows 是 `224` + 一个码，Linux/macOS 是 `ESC [ A` 三个字节），初学者处理起来容易踩坑。用单字符的 WASD 逻辑最干净。当成进阶练习，你可以自己试着把方向键加上。

## 规则

- 吃到食物 `*` 得 10 分，蛇变长一节，速度加快 5 毫秒
- 撞到墙 `#` 或撞到自己身体 → 游戏结束
- 蛇头不能直接 180 度掉头

## 这个项目用到的知识点

**基础语法**

- `#define` 宏定义、`enum` 枚举、`const` 常量
- 一维数组、二维数组、数组越界
- `for` / `while` / `do-while` 三种循环
- `switch-case`（含故意的 fall-through 写法）
- 函数定义、参数传递、返回值
- 全局变量与 `static` 变量的区别
- `#ifdef` 条件编译

**标准库**

- `<stdio.h>`：`printf`、`fflush`
- `<stdlib.h>`：`rand`、`srand`、`exit`、`atexit`
- `<time.h>`：`time(NULL)` 取随机种子
- `<conio.h>`（Windows）：`_kbhit`、`_getch` 实现"按键不阻塞"

**核心算法与思想**

- **用数组存蛇身**：`snake_x[i]` + `snake_y[i]` 表示第 `i` 节，蛇头是 0 号
- **从后往前挪数组**做移动（写反了蛇会缩成一团，这是本项目最容易错的地方）
- **双缓冲**：先拼好整屏字符数组再一次性输出，避免画面闪烁
- **游戏主循环**：读输入 → 更新状态 → 渲染 → 等待，循环往复
- 用 `dir ^ 1` 判断反方向（0↔1、2↔3 是相反方向）

## 常见问题

**Q：编译报错 `'conio.h' file not found`？**
你在 Linux/macOS 上。代码已经用 `#ifdef _WIN32` 分开了，理论上不会报这个错；如果报了，说明编译器没进 `_WIN32` 分支，检查一下是不是用了交叉编译工具链。

**Q：运行后画面一直在滚屏，不停往下刷？**
说明你运行的是 `step2_snake.c`，它每帧都重新 `printf` 一整屏，没有清屏。`snake.c` 用 `gotoxy()` 把光标固定回左上角覆盖重写，就不闪了。

**Q：蛇走到墙边就卡住不动？**
检查 `read_input()` 里的方向判断。如果 `dir` 和 `next_dir` 同步更新，就会出现"按一下掉头撞死"或者方向被吃掉的情况；正确做法是先存到 `next_dir`，在每帧开头再校验一次。

**Q：吃了食物蛇没变长？**
一定要在挪动数组**之前**把旧尾巴坐标存进 `tail_x/tail_y`。挪完之后旧尾巴那格已经被覆盖了，再去读就是错的位置。

**Q：中文显示乱码？**
Windows 的 cmd 默认用 GBK。运行前执行 `chcp 65001` 切换到 UTF-8，或者把终端换成 Windows Terminal。

## 进阶练习（做完这些你就不是初学者了）

1. **加方向键支持**：Windows 下 `_getch()` 遇到方向键会先返回 224，再返回 72/80/75/77；试着处理它。
2. **最高分记录**：开局时从 `highscore.txt` 读最高分，结束时写回去。练习文件读写 `fopen/fprintf/fscanf`。
3. **障碍物**：在棋盘上随机放几块石头，撞上去也死。
4. **穿墙模式**：从左边出去从右边进来，只要把坐标取模 `% WIDTH` 就行。
5. **彩色版**：给蛇头、身体、食物加上 ANSI 颜色码 `\033[31m`。
6. **重构成结构体**：把 `snake_x / snake_y / len / dir` 打包成 `struct Snake`，函数改成传指针。这是从"能跑"走向"好维护"的第一步。
